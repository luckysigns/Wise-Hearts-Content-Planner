One-time setup

Connect your Supabase

This is where your numbers live, so every device stays in sync. Takes about five minutes, and the free plan is plenty.

  1. Go to supabase.com, sign up (free), and create a New project — name it anything, e.g. wise-heart.
  2. In the left menu open SQL Editor, paste the whole supabase-setup.sql file that came with this app, and press Run. That creates the table and imports all 72 weeks of your spreadsheet.
  3. Open Project Settings → API, copy the Project URL and the anon public key, and paste them below.
